# Receta: El mayor de tres números

1. MOSTRAR "Bienvenido a mi programa"

2. LEER el primer número y guardarlo en numero1

3. LEER el segundo número y guardarlo en numero2

4. LEER el tercer número y guardarlo en numero3

5. GUARDAR numero1 como el mayor

6. SI numero2 es mayor que mayor ENTONCES
       GUARDAR numero2 como el mayor

7. SI numero3 es mayor que mayor ENTONCES
       GUARDAR numero3 como el mayor

8. MOSTRAR "El número mayor es:" y el valor de mayor

9. TERMINAR
